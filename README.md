# Weather Alert Dashboard

## Overview

A dynamic weather monitoring system that fetches real-time weather data and generates alerts.

---

## Features

- Live weather API integration
- Temperature monitoring
- Automatic alert generation
- Real-time weather tracking

---

## Files

- `fetch_weather.py`
- `alerts.py`

---

## Installation

```bash
pip install requests
```

---

## Usage

```bash
python fetch_weather.py
python alerts.py
```

---

## Example

```text
Enter City: Surat

Temperature: 38°C

Heat Alert
```
